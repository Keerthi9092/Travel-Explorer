# Travel Explorer

A professional React + Bootstrap travel explorer project with no backend.

## Features
- Responsive home page
- Destination exploration and search
- Destination details
- Live country information using REST Countries API
- Live weather using Open-Meteo API
- Favourites using localStorage
- Trip planner using localStorage
- React Router navigation
- Reusable components and page folders

## Run
```bash
npm install
npm run dev
```

## Public APIs
- REST Countries: https://restcountries.com/
- Open-Meteo: https://open-meteo.com/
